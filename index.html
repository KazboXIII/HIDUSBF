up to 8,000 Hz

Polling rate

Pick a rate for any USB mouse, keyboard or controller: 250, 500, 1000, 2000, 4000 or 8000 Hz. HIDUSBF installs SweetLow's hidusbf filter driver, attaches it to the device you choose and restarts the device for you.

The live input panel shows the real report rate, so you can see whether the device keeps up.

DualSense · DualSense Edge · DualShock 4

Controller calibration

Correct stick-center offsets, teach the controller each stick's full range, or fine-tune the stored values while you watch the stick check. Calibration cannot repair worn or damaged hardware.

Smart calibration re-measures both sticks and sets how they feel: Loose for lighter, quicker aim or Tight for steadier aim. It's stored on the controller, so it works in every game.

Changes stay temporary until you save them, and every connection keeps a snapshot you can restore.

Which controllers? Genuine DualSense and DualSense Edge get everything: center, range, fine-tune and the Loose or Tight feel. DualShock 4 (V1 and V2) gets center and range. Calibration needs a USB cable. Clones aren't supported. Xbox, Nintendo, GameSir, SCUF and other controllers get the polling rate only.

Lights

Set your controller's light bar and player LEDs, and the per-key lighting on a SteelSeries Apex Pro TKL Gen 3. Your colors are saved.

Profiles

Save a controller's settings as a profile and switch between them from the top of the page. Lights and trigger resistance come back every time it connects.

Install

  1. 1

    Download and run the installer

    It installs to Program Files and adds HIDUSBF to the Start menu. HIDUSBF needs administrator rights because it manages a driver.

  2. 2

    Install the driver once

    Open Driver in the sidebar and install the service. The first-start tour walks you through it.

  3. 3

    Pick a device and a rate

    Open a device, turn on the filter, choose a rate and restart the device. Re-plug it or reboot if the rate doesn't change.

SmartScreen warning? The installer isn't code-signed yet. Choose More info, then Run anyway. Each release has a .sha256 file if you want to check the download.

Uninstalling leaves the driver in place. To remove it, turn the filter off on every device, then uninstall the service from Driver before removing the app.

Results vary. How fast a device can really report depends on the device and your USB controller. The live input panel shows what you actually get.
